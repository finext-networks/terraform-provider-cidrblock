# Security Policy

## Reporting a Vulnerability

We take the operational integrity of our network calculation layers seriously. 
If you discover a layout bypass, bit-saturation overflow, or denial-of-service 
vulnerability within the calculation engine, please **do not open a public issue**.

Instead, please report the vulnerability privately by emailing the maintainers 
at `support@finext.net`.

## Supported Versions

Security updates and patches are evaluated and delivered exclusively for the 
current active stable release branch track (`main`).
